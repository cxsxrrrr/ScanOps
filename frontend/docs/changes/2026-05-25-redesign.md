## Patrón de Toasts (Sonner)

Antes: cada página tenía estados `saved`, `error`, `success` con `setTimeout`.
Ahora: `toast.success('mensaje')` / `toast.error('mensaje')` desde cualquier componente.
El `<Toaster>` está en `src/main.jsx`.

---

## Patrón AbortController

Aplicado en todos los `useEffect` que hacen peticiones API:

```js
useEffect(() => {
    const controller = new AbortController()
    loadFn(controller.signal)
    return () => controller.abort()
}, [])
```

Las funciones de carga aceptan `signal` como parámetro opcional para soportar llamadas manuales (reload tras mutación).
